# Explain Like I'm 10 — конвейер коротких видео

Полностью бесплатная замена HeyGen: голос, графика, анимация и монтаж
собираются локально одной командой. Подписок нет, ключей нет.

## Что стоит и почему

| Задача | Чем решено | Цена |
|---|---|---|
| Монтаж/кодирование | **ffmpeg 9.0.2** (полная сборка evermeet с libass/freetype) | 0 |
| Голос | **edge-tts** — нейронные голоса Microsoft + тайминги по словам | 0 |
| Графика, персонаж | **Pillow**, свой код — `art.py` | 0 |
| Субтитры | **libass**, генерим ASS с подсветкой слова | 0 |

> Homebrew на этой машине для ffmpeg не годится: для macOS 12 бутылок больше нет,
> `brew install ffmpeg` уходит в сборку из исходников на часы. Поэтому бинарник
> берётся из колеса `imageio-ffmpeg` — это та же официальная сборка.

Установка с нуля:

```bash
pip3 install imageio-ffmpeg edge-tts Pillow
```

## Как сделать видео

```bash
cd pipeline
python3 make_video.py ../scripts/renting.json
```

Готовый mp4 (1080×1920, H.264) ляжет в `out/`.
На MacBook Air 2015 ролик на 45 секунд собирается примерно за 2 минуты.

Пачкой — всё, что лежит в `scripts/queue/`:

```bash
./run.sh
```

Отрендеренные сценарии переезжают в `scripts/done/`, сбой одного не роняет остальные.

## Формат сценария

```jsonc
{
  "slug": "renting-not-wasted",        // имя файла на выходе
  "voice": "en_m",                     // en_m | en_f | en_gb | ru_m | ru_f
  "rate": "+6%",                       // темп речи
  "caption_size": 76,
  "scenes": [
    {
      "bg": "outdoor",                 // outdoor | board
      "headline": ["Строка 1", "Строка 2"],
      "highlight": 1,                  // какую строку выделить красным
      "poses": ["talk", "present"],    // позы чередуются
      "char_scale": 1.45,
      "char_y": 0.845,                 // где у персонажа ступни (доля высоты)
      "say": "Текст, который произносит голос."
    },
    {
      "bg": "board",
      "character": false,
      "diagram": { "kind": "bars", "items": [["rent", 0.62, "green"]] },
      "say": "..."
    }
  ]
}
```

**Позы:** `idle`, `talk`, `present`, `shrug`, `point`, `think`, `walk`, `cheer`, `slump`.

**Диаграммы:**

- `bars` — столбики: `items: [[подпись, 0..1, "green"|"red"], ...]`
- `growth` — кривые роста: `labels: ["spend it", "invest it"]`
- `stack` — доли (например 50/30/20): `items: [[подпись, доля], ...]`
- `lines` — крупный текст: `items: [...]`, `highlight: N`

## Из чего собрано

```
pipeline/
  config.py      палитра (снята с существующих роликов канала), шрифты, размеры
  art.py         фоны и параметрический риг персонажа
  scenes.py      плашки заголовков, диаграммы, артикуляция рта
  subs.py        ASS-субтитры с подсветкой слова
  make_video.py  сборка одного ролика
  run_batch.py   очередь
assets/cache/    фоны кэшируются после первой отрисовки
```

Рот открывается по реальным таймингам слов из edge-tts, а не по таймеру —
поэтому артикуляция попадает в речь.

## Известные особенности

- edge-tts иногда отдаёт пустой ответ; в `tts.py` встроены 5 попыток с паузами.
- Фоны кэшируются в `assets/cache/`. Удали файл — перерисуется заново.
- Громкость нормализуется в `-14 LUFS` (норма для YouTube).
